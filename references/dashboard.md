# 看板（可选）

用户说要「看板 / 前端 / 网页 / 可视化」才做，默认不做。

目标是打开就能看到这套日记长什么样、坚持得怎么样。**只在本地看，不部署到公网**——数据是私人的。

## 做法

写一个零依赖的小脚本（Python 或 Node 都行），读 `journal/**/*.md` 和 `language-bank.md`，生成一个单文件 `dashboard.html`
（数据内嵌成 JSON，样式和脚本都内联），浏览器双击就能开。每次入库后重跑一次脚本，回报里说一句「看板已更新」。
`dashboard.html` 已经在工作区的 `.gitignore` 里。

解析只靠两样东西：frontmatter，和结束 Prompt 里固定的二级标题。某一篇解析失败就在页面上标出来，不要静默跳过。

## 页面

| 页 | 放什么 |
|---|---|
| 首页 | 日历热力图（哪天有日记）、连续天数、最长连续、总篇数、词库条数、最近一次口语评分 |
| 日记 | 按日期选；同一天有两份就能切换；按二级标题分节显示 |
| 纠错 | 所有 Better English 行汇总，按日期倒序 |
| 今日表达 | 最近一篇的 New Vocabulary 和 Polished Sentences |
| 词库 | 表格，能按 Status、Next review 筛选，到期的标出来 |
| 走势 | 口语总分和四个维度的折线；打卡数字有才画 |
| Prompt | 开始 / 结束两段全文，各带一个「复制」按钮 |

## 录屏、截图之前

加一个「演示模式」开关：打开后日记正文、打卡数字、例句都换成灰色色块，只留页面结构、日期、评分和 Prompt。
用 CSS 换成色块，不要只加模糊——模糊在某些元素上不生效，截出来还能看清原文。
